# AI Friends (Fabric, Minecraft 26.3)

Spawn an army of player-skinned companions that follow commands, use gear you give them, and reply in chat.

- `/friend spawn <name> [count] [skin username]`
- `/friend <name|squad|all> <follow|come|stay|guard|wander|attack|passive|aggressive|status|drop|dismiss>`
- `/friend give <who>` and `/friend skin <who> <username>`, `/friend list`, `/friend help`
- Or type in chat: "bob follow me", "everyone attack", "hi squad"

GitHub Actions builds the jar on every push (Actions tab -> latest run -> Artifacts).
